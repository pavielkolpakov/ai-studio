# RAG Module

LangChain 1.0 agent with `read_knowledge_base` + `generate_project_ideas` tools. No embeddings/vector store — knowledge is served as plain text from the `docs/vault/` markdown vault (see `app/vault/loader.py`).

- `chain.py` - `build_agent()` wires `create_agent` with both tools + `GuardrailMiddleware`, injecting the vault routing index into the system prompt (`AGENT_SYSTEM_PROMPT.replace("{index}", load_index())`). `read_knowledge_base(names)` returns the full text of the requested vault notes on demand (via `app.vault.loader.read_notes`); the agent picks note names from the injected index. `stream_response()` emits SSE events: `{type: "tool_call", tool, query}` (`query` is the joined note names for `read_knowledge_base`, else the ideas description), `{type: "token", token, done: false}`, `{type: "ideas", ideas}`, `{type: "done", followups}`. `followups` is populated by `pick_followups()` for freeform responses (`[]` on picker failure); when ideas were emitted, returns a fixed set: services_pricing, process_overview, about_neuronetis.
- `ideas.py` - embedding-free two-step. `select_projects(description)` shows all `docs/vault/projects/` notes (name + title + read_when) to gpt-4o-mini and gets back 2-3 names (`ProjectSelection`); falls back to the first 3 on an unknown pick. `generate_ideas_payload(description)` feeds the selected notes' bodies to a structured-output LLM (tagged `"ideas"`, streaming off) that lightly adapts each; tech/price_range/time_estimate are copied verbatim per prompt instruction. `IdeasPayload`/`Idea` schemas (`ideas` constrained to 2-3).
- `guardrail.py` - `GuardrailMiddleware.before_model` runs `classify_query` on first-turn Human messages only; rejection short-circuits via `Command(goto=END, update={messages: [AIMessage(REJECTION_MESSAGE)]})` so rejection streams as normal AI tokens.
- `prompts.py` - `AGENT_SYSTEM_PROMPT` (persona + tool-use instructions; `{index}` placeholder filled at agent-build time) + `GUARDRAIL_PROMPT` (topic classifier YES/NO). `IDEAS_SELECTION_PROMPT` (pick 2-3 project names from the catalog menu) + `IDEAS_GENERATION_PROMPT` (adapt the selected entries, copying tech/price/time verbatim).
- `followups.py` - `pick_followups(user_msg, assistant_msg)` calls gpt-4o-mini with strict JSON schema to pick 3 ids from `app.data.followup_pool.PICKABLE_IDS`. Runs only for freeform LLM responses (not when ideas were emitted). Returns `[]` on any failure - frontend renders nothing then appends Book a Call via <2-fallback.
