# RAG Module

LangChain 1.0 agent with `search_knowledge_base` + `generate_project_ideas` tools.

- `chain.py` - `build_agent()` wires `create_agent` with both tools + `GuardrailMiddleware`. `search_knowledge_base(query)` retrieves across all topics; `generate_project_ideas(description)` retrieves only from `topic=projects_catalog` (k=2). `stream_response()` emits SSE events: `{type: "tool_call", tool, query}`, `{type: "token", token, done: false}`, `{type: "ideas", ideas}`, `{type: "done", followups}`. `followups` is populated by `pick_followups()` for freeform responses (`[]` on picker failure); when ideas were emitted, returns a fixed set: services_pricing, process_overview, about_neuronetis.
- `ideas.py` - `get_catalog_retriever()` (Qdrant filtered to `topic=projects_catalog`, k=2); `IdeasPayload`/`Idea` schemas; `generate_ideas_payload(description)` runs a single retrieval + structured-output LLM (tagged `"ideas"`, streaming off).
- `guardrail.py` - `GuardrailMiddleware.before_model` runs `classify_query` on first-turn Human messages only; rejection short-circuits via `Command(goto=END, update={messages: [AIMessage(REJECTION_MESSAGE)]})` so rejection streams as normal AI tokens.
- `prompts.py` - `AGENT_SYSTEM_PROMPT` (plain str, persona + tool-use instructions, tells agent to rephrase follow-ups itself) + `GUARDRAIL_PROMPT` (topic classifier YES/NO). `IDEAS_GENERATION_PROMPT` instructs the LLM to anchor price/time on the catalog entries returned by retrieval.
- `followups.py` - `pick_followups(user_msg, assistant_msg)` calls gpt-4o-mini with strict JSON schema to pick 3 ids from `app.data.followup_pool.PICKABLE_IDS`. Runs only for freeform LLM responses (not when ideas were emitted). Returns `[]` on any failure - frontend renders nothing then appends Book a Call via <2-fallback.
